# 🏫 Sistema de Gestión Escolar

El **Sistema de Gestión Escolar** es una aplicación web Full-Stack desarrollada para centralizar y optimizar la administración académica en instituciones educativas. La plataforma permite gestionar entidades clave del entorno escolar mediante un panel de control interactivo, unificado y fácil de usar.

---

## Descripción General

El sistema está estructurado bajo una arquitectura cliente-servidor desacoplada: consume endpoints RESTful construidos en el Backend y los presenta en un Frontend dinámico e interactivo mediante JavaScript asíncrono (`fetch`).

La aplicación está dividida en tres módulos interconectados mediante relaciones relacionales sólidas:

**Gestión de Profesores:** Registro y administración del cuerpo docente, incluyendo especialidades e información de contacto.
**Gestión de Cursos:** Creación y control de asignaturas escolares, códigos de identificación y vinculación directa con el profesor titular.
**Gestión de Estudiantes:** Matriculación de alumnos, asignación de grado académico y selección dinámica del curso al que pertenece el estudiante.
